# study_noise

I am creating these notes to reuse calculations—whether originally performed or subsequently re-verified—that I have frequently used in fields such as sensor and audio signal processing. I intend to correct any terminology or inaccuracies as I go.

## Quick Start

Install the development environment with uv:

```bash
uv sync --group dev
```

Run Experimental code.

```bash
uv run pytest ./misc/whitenoise.py
```


Run tests:

```bash
uv run pytest
```
